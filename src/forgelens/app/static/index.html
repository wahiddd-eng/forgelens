Examine a statement

Upload a bank statement as a PDF, a screenshot or a photo. ForgeLens re-adds its figures, reads how the file was built, looks at its pixels and shows you where it found evidence.

Lets ForgeLens compare the statement with that bank's layout and genuine statements.

Used once to open the file, never stored.

The file is examined on this server and deleted as soon as the result is ready.

This is a preview. Uploading works when ForgeLens runs on the GPU server; here you can open fictional statements examined in advance with the rule-based checks.
